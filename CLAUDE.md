# Apprenticeship Business Dashboard

## Project Overview
A demo dashboard for an apprenticeship business, built with realistic dummy data. The dashboard provides:
- **Visual data** in tabulated format, downloadable as a Google Sheets-compatible file
- **Actionable data** to drive performance and support daily management duties

## Tech Stack
- **HTML** — structure (`index.html`)
- **CSS** — styling (`style.css`)
- **JavaScript** — logic and data (`app.js`)
- **localStorage** — data persistence (no backend, no database)

## File Rules
- Keep all code in exactly **three files**: `index.html`, `style.css`, `app.js`
- **Do not add new libraries** (e.g. Chart.js, Bootstrap, etc.) without asking the user first

## Running the App
Open `index.html` directly in a browser — no build step, no server needed.

## Hosting
Hosted on **GitHub Pages** from the `main` branch.

## Data
All data is dummy/realistic placeholder data generated for demo purposes.
Data is stored in `localStorage` so changes persist across browser sessions.
